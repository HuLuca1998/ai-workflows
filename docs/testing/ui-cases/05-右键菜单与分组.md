# 05 · 右键菜单与分组

画布上有四种右键菜单：节点 / 连线 / 分组 / 空白。
每个菜单项都翻译成结构化 Patch —— **没有任何一个动作是「整份回写」**。

## 元素清单

### 四种菜单的项

| 目标 | 菜单项                                                               |
| ---- | -------------------------------------------------------------------- |
| 节点 | 编辑配置 / 复制 / 断开全部连线 / 用选中节点建分组 / **删除**（危险） |
| 连线 | 切换源端口… / 反转方向 / 在连线上插入节点… / **删除连线**（危险）    |
| 分组 | 重命名… / **解散分组**（危险）                                       |
| 空白 | 用选中节点建分组                                                     |

带 `…` 的项需要**二级选择或输入**。危险项在界面上单独标出（`data-danger`）。

### 禁用与原因

| 菜单项           | 什么时候禁用       | 禁用原因（悬停可见）         |
| ---------------- | ------------------ | ---------------------------- |
| 断开全部连线     | 该节点没有连线     | 「这个节点还没有连线」       |
| 用选中节点建分组 | 选中数 < 2         | 「先选中两个以上节点」       |
| 切换源端口…      | 源节点只有一个输出 | 「这个节点只有一个输出端口」 |

---

## 用例

### MENU-01 · 四种菜单各自出现在正确的目标上

- 类型：功能
- 操作：依次右键：一个节点、一条连线、一个分组框、画布空白
- 预期：
  1. 菜单出现在**鼠标位置**
  2. 四种菜单的项与上表一致，不多不少
  3. 菜单本身 `role="menu"`，每项 `role="menuitem"`
  4. 危险项（删除类）有独立的视觉标记
- 失败判定：右键节点却出了空白菜单（事件冒泡没拦住）

### MENU-02 · 关闭菜单的三种方式

- 类型：功能
- 操作：
  1. 打开菜单 → 按 Esc
  2. 打开菜单 → 点画布空白
  3. 打开菜单 → 在菜单上再右键
- 预期：
  1. Esc 关闭
  2. 点空白关闭
  3. **在菜单上右键不会把菜单关掉又重开**（`preventDefault` 拦住了）
- 失败判定：菜单关不掉；或右键菜单自己触发新菜单

### MENU-03 · 节点 · 编辑配置

- 类型：功能
- 操作：右键节点 → 「编辑配置」
- 预期：菜单关闭，配置弹层打开，且打开的是**那个**节点
- 失败判定：打开的是别的节点；或菜单没关

### MENU-04 · 节点 · 复制

- 类型：功能
- 操作：右键一个已配置好的节点 → 「复制」
- 预期：
  1. 出现一个新节点，标题是「<原标题> 副本」
  2. 位置在原节点**右下偏移**（不叠在原节点上）
  3. 配置与原节点相同
  4. **连线不复制**
  5. 节点数 +1，dirty
- 失败判定：副本叠在原节点上看不出来

### MENU-05 · 节点 · 断开全部连线

- 类型：功能 / 边界
- 操作：
  1. 右键一个**有连线**的节点 → 「断开全部连线」
  2. 右键一个**没有连线**的节点 → 看该项
- 预期：
  1. 与该节点相关的**入边与出边全部消失**，节点本身还在
  2. 连接数减少的数量 = 原来相关边的数量
  3. 没有连线的节点上，该项**禁用**，悬停显示「这个节点还没有连线」
- 失败判定：只断了出边；或禁用但没说原因

### MENU-06 · 节点 · 删除

- 类型：功能
- 操作：右键一个有连线的节点 → 「删除」
- 预期：
  1. 节点消失
  2. 相关连线**一并消失**（不留悬空边）
  3. 校验状态可能变化（删了 entry 会报 ENTRY_MISSING）
- 失败判定：留下悬空边

### MENU-07 · 删除 entry 节点是允许的

- 类型：边界
- 操作：右键 entry 节点 → 「删除」
- 预期：**允许删除**（用户可能要换一个），删完后校验报「缺少入口节点」
- 说明：入口删掉后工作流无从启动，但**仍允许删**——
  这是有意的设计。确认它没有被禁用。
- 失败判定：被禁用且没有说明

### MENU-08 · 连线 · 删除

- 类型：功能
- 操作：右键一条连线 → 「删除连线」
- 预期：那条连线消失，两端节点都在，连接数 -1
- 失败判定：删错了另一条

### MENU-09 · 连线 · 反转方向

- 类型：功能 / 边界
- 操作：
  1. 右键 A→B 的连线 → 「反转方向」
  2. 右键一条**指向 entry** 的连线（如果能造出来）→ 「反转方向」
  3. 右键一条**从 end 出发**的连线 → 「反转方向」
- 预期：
  1. 变成 B→A，且源端口取 B 的第一个输出端口
     2/3. 反转后不合法时（如反转后从 end 出发）**什么都不做**，不报错也不产生半条边
- 失败判定：产生了非法的边

### MENU-10 · 连线 · 切换源端口

- 类型：功能
- 前置：一条从**有多个输出端口**的节点出发的连线（如条件分支、审批、AI 决策）
- 操作：
  1. 右键那条连线 → 「切换源端口…」
  2. 观察二级列表
  3. 选一个别的端口
- 预期：
  1. 二级列表显示「选择源端口」+ 该节点的全部输出端口
  2. 当前端口后面标着「· 当前」（`data-current="true"`）
  3. 有「返回」可以退回一级菜单
  4. 选完之后连线的源端口变了（在配置弹层的输入/输出 tab 能验证）
  5. 底层是「断开 + 重连」两个操作，Diff 上能看清是哪条边变了
- 失败判定：切换后连线消失；或选了没变化

### MENU-11 · 只有一个输出端口时该项禁用

- 类型：边界
- 操作：右键一条从**只有一个输出**的节点出发的连线
- 预期：「切换源端口…」禁用，悬停显示「这个节点只有一个输出端口」
- 失败判定：可点但点了没反应

### MENU-12 · 连线 · 在连线上插入节点

- 类型：功能
- 操作：
  1. 右键 A→B 的连线 → 「在连线上插入节点…」
  2. 在二级列表里选「Shell 脚本」
- 预期：
  1. 二级列表标题「插入哪种节点」，列出全部节点类型，**可滚动**
  2. 选完之后：
     - 新节点出现在 A 与 B **之间偏下**的位置
     - 原来的 A→B 连线**消失**
     - 出现 A→新节点、新节点→B 两条连线
     - 节点数 +1，连接数 +1（-1 +2）
  3. 新节点带最小配置（必填项是占位值），校验会报问题
- 失败判定：插入后原连线还在（变成三条边）；或新节点没接上

### MENU-13 · 建分组

- 类型：功能
- 操作：
  1. 只选中 1 个节点 → 右键 → 看「用选中节点建分组」
  2. 框选 3 个节点 → 右键其中一个 → 「用选中节点建分组」
  3. 输入分组名「预处理」→ 确定
- 预期：
  1. 选中 <2 时该项**禁用**，悬停显示「先选中两个以上节点」
  2. 二级表单显示「分组名称」输入框，自动聚焦
  3. 确定后画布上出现**虚线框**围住那 3 个节点，左上角显示「预处理」
  4. 框比节点外扩一圈（约 18px），跟着节点位置走
- 失败判定：分组框位置不对；或框住了没选中的节点

### MENU-14 · 分组名留空

- 类型：边界
- 操作：建分组时不输入名字直接确定
- 预期：使用默认名「新分组」
- 失败判定：产生一个没有标题的框

### MENU-15 · 分组跟着节点移动

- 类型：功能
- 操作：建好分组后，拖动其中一个成员节点到远处
- 预期：分组框**重新计算**包围盒，仍然框住全部成员
- 失败判定：框不动，成员跑出框外

### MENU-16 · 分组 · 重命名

- 类型：功能
- 操作：右键分组框 → 「重命名…」→ 输入「新名字」→ 确定
- 预期：
  1. 二级表单标签是「新的分组名」
  2. 确定后标题变了，**成员不变**
- 失败判定：重命名后分组成员丢了（底层是删除+重建，成员必须保留）

### MENU-17 · 分组 · 解散

- 类型：功能
- 操作：右键分组框 → 「解散分组」
- 预期：
  1. 虚线框消失
  2. **节点全都还在**（只解散分组，不删节点）
- 失败判定：节点跟着没了（**数据丢失，阻塞级**）

### MENU-18 · 删光成员的分组

- 类型：边界
- 操作：建一个分组 → 把成员节点全删掉
- 预期：分组框不再显示（成员为空不出框），但分组数据还在——
  再往里拖节点时应能恢复显示
- 失败判定：报错或画布崩溃

### MENU-19 · 二级菜单的返回与取消

- 类型：功能
- 操作：
  1. 进入「切换源端口…」的二级列表 → 点「返回」
  2. 进入「重命名…」的表单 → 点「返回」
- 预期：都回到一级菜单，不执行任何操作
- 失败判定：返回后菜单直接关了；或执行了操作

### MENU-20 · 菜单出现在屏幕边缘

- 类型：边界
- 操作：在画布**最右下角**右键
- 预期：菜单完整可见（不被窗口边缘截断到点不到）
- 失败判定：菜单一半在屏幕外

### MENU-21 · 菜单里的操作都能被撤销吗

- 类型：体验
- 操作：做一次「删除」，然后找撤销
- 预期：工具栏的撤销是**禁用**的（已知，标为待实现）
- 说明：那么用户误删之后怎么办？记录他能走的路：
  不保存直接刷新？从版本回滚？
  这条不判 FAIL，但**写进报告的建议**——破坏性操作没有撤销是真实风险。

### MENU-22 · 键盘能不能用右键菜单

- 类型：无障碍
- 操作：见 [F2 剧本 K1](personas/F2-交互健壮性.md)
- 预期：至少要能用键盘打开菜单（Shift+F10 或菜单键）并用方向键选择
- 说明：做不到的话，**画布上一半的功能对键盘用户不存在**——
  删除、复制、分组、切换端口、插入节点全都只在右键菜单里。
