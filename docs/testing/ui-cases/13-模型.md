# 13 · 模型

路由 `/models`。图纸「07 模型」：262px 左栏（按接入方式分组）+ 详情。

两条产品规则在这一屏兑现：

1. **系统内所有模型下拉只列已启用的条目**——停用是一等操作
2. **凭据只显示 `keychain://` 引用**——界面上**不存在**查看明文的路径
   （留一个「显示明文」按钮，等于把密钥搬到截图与录屏里）

> **ACP 相关的测试一律用 `acp.codex`**，不要用 `acp.claude`（CLAUDE.md 纪律）：
> 这个应用本身跑在 Claude Code 里开发，用 claude adapter 测会与开发会话撞在一起。

## 用例

### MDL-01 · 空态

- 类型：功能
- 前置：一条模型都没有
- 预期：左栏显示空态那句话（一字不差），详情区显示「选一个模型查看详情，或登记一个新的。」
- 失败判定：空白

### MDL-02 · 登记模型

- 类型：功能
- 操作：
  1. 点 `+`
  2. 观察表单字段
  3. 填名称、接入方式选「Codex（ACP）」、模型 ID、档位、上下文窗口
  4. 点「保存」
- 预期：
  1. 表单标题「登记模型」
  2. 字段：名称 / 接入方式 / 模型 ID / 推理档位 / 上下文窗口 / 凭据
  3. 接入方式下拉的三个选项显示中文名
  4. 保存后出现在左栏对应的分组下，默认**已启用**
- 失败判定：保存没反应（多半是 runtime 值写错被 Zod 挡在 Core API 门口，
  症状就是「保存没反应」——这个坑踩过一次）

### MDL-03 · 必填校验

- 类型：功能
- 操作：只填名称就点「保存」
- 预期：显示「名称、模型 ID 与上下文窗口是必填项。」，不发请求
- 失败判定：发了请求让后端报错

### MDL-04 · 凭据必须是 keychain:// 引用

- 类型：安全（**核心规则**）
- 操作：凭据填 `sk-TESTLEAK-1234567890` → 点「保存」
- 预期：
  1. 显示「凭据必须是 keychain:// 引用。请先把密钥存进钥匙串，再在这里引用它。」
  2. **网络面板里 `model_create` 请求根本没发出去**
     （让它走到 IPC 再报错，那一路上它已经出现在日志与错误上报里了）
- 失败判定：请求发出去了（即使后端也拒绝，也算缺陷）
- 补充：大小写、前导空格等绕过手法见
  [B3 剧本 S2](personas/B3-安全与可解释性.md)

### MDL-05 · 凭据只显示引用

- 类型：安全
- 操作：登记一个带 `keychain://openai/default` 的模型，看详情
- 预期：
  1. 凭据一行显示 `keychain://openai/default`
  2. **没有任何按钮/菜单/悬停能看到明文**
  3. 没设置时显示「未设置」
- 失败判定：出现「显示明文」这类入口（**阻塞级**）

### MDL-06 · 上下文窗口的格式

- 类型：功能 / 边界
- 操作：
  1. 登记时填 `200000`
  2. 看详情
  3. 再登记一个填 `abc`
  4. 填 `-1`、`0`、`1.5`
- 预期：
  1. 详情显示千分位「200,000」
  2. `abc` 应被拦住（不能变成 `NaN`）
  3. 负数与 0 的行为记录下来
- 失败判定：详情显示 `NaN`

### MDL-07 · 推理档位是展示器不是控件

- 类型：功能 / 无障碍
- 操作：看详情的「推理档位」四个按钮
- 预期：
  1. 四个按钮**全部禁用**
  2. 当前档位用 `aria-pressed="true"` + `data-active` 标出
     （四个按钮 class 完全相同又没有语义的话，读屏用户与灰度截图都读不出当前档位）
  3. 下方两句说明都在
- 失败判定：能点却没反应；或读屏读不出当前是哪一档

### MDL-08 · 启用 / 停用

- 类型：功能
- 操作：
  1. 点「停用」
  2. 观察左栏与详情
  3. 点「启用」
- 预期：
  1. 详情的徽章与左栏条目的状态**同时**变成「已停用」
  2. 按钮文字在「停用」/「启用」之间切换
  3. 停用的条目**仍在列表里**
- 失败判定：停用后条目消失

### MDL-09 · 停用后所有下拉里都不再出现

- 类型：功能 / 可解释性（**核心规则**）
- 操作：停用模型 A，然后去这些地方看下拉：
  1. Agent 角色的「模型」下拉
  2. Agent 角色的「降级模型」下拉
  3. 主管 AI 抽屉顶部的模型下拉
  4. AI 节点配置里的模型选择（如果有）
- 预期：**四处都没有 A**
- 失败判定：某一处还能选到（过滤没放在后端，某处忘了筛）

### MDL-10 · 已被引用的模型被停用

- 类型：边界
- 操作：某个 Agent 绑着 A → 停用 A → 看那个 Agent
- 预期：下拉里保留 A 并标注「（已停用或已删除）」，不悄悄跳到第一项
  （详见 [11](11-Agent角色.md) AGT-06）

### MDL-11 · 测试连通性

- 类型：功能
- 操作：选一个 ACP 模型 → 点「测试连通性」
- 预期：
  1. 按钮变成「测试中…」并禁用
  2. 完成后显示结果：图标 + 详情文字（`role="status"`）
  3. **凭据卡上的「延迟」一行跟着更新**（不更新的话用户以为测试没生效）
  4. 只做握手 + 建会话，**不发提示词**（快、不花钱）
- 失败判定：测完延迟还是上一次的数字

### MDL-12 · adapter 没装时的测试结果

- 类型：体验（**最常见的情况**）
- 前置：把 codex adapter 从 PATH 里去掉（或测一个肯定没装的 runtime）
- 操作：点「测试连通性」
- 预期：
  1. 结果是 `ok=false` 而**不是抛错**
  2. 详情文字告诉用户**装什么**（不是一个红色的「失败」）
- 失败判定：只显示「测试失败」——用户需要的是「装什么」

### MDL-13 · 连点「测试连通性」

- 类型：边界
- 操作：连点 5 次
- 预期：按钮禁用期间不叠加请求
- 失败判定：发出 5 次

### MDL-14 · 删除与二次确认

- 类型：功能 / 边界
- 操作：
  1. 点「删除」
  2. 观察警告
  3. 切到另一个模型再切回来
  4. 点「删除」→「确认删除」
- 预期：
  1. 按钮变「确认删除」
  2. 警告：「删除后引用这个模型的 Agent 与节点会失效。确认要删除吗？」
  3. **切换条目后确认态被清掉**
  4. 确认后模型消失，详情区回到未选中态
- 失败判定：确认态残留（在别的模型上点一下就删错了）

### MDL-15 · 删除被引用的模型

- 类型：边界
- 操作：某 Agent 绑着 A → 删掉 A → 看那个 Agent
- 预期：下拉里显示 `<id>（已停用或已删除）`，且界面能看出它失效了
- 失败判定：静默变成别的模型

### MDL-16 · 按接入方式分组

- 类型：功能
- 前置：三种接入方式各登记两个
- 预期：
  1. 分成三组，组标题是中文显示名
  2. 每组标题右侧的数字 = 组内条数
  3. 组内顺序稳定
- 失败判定：分组计数不对；或显示英文 id

### MDL-17 · 这一屏没有搜索框

- 类型：体验 / 一致性
- 操作：找搜索框
- 预期：**记录实际情况**——当前这一屏没有搜索
- 判定：Agent 页与提示词页都有搜索，这一屏没有 →
  一致性缺口。模型多起来（几十个）时怎么找？记进建议。

### MDL-18 · 能力标签

- 类型：功能
- 操作：看「能力标签」卡
- 预期：
  1. 列出该模型的能力
  2. 说明：「不具备「结构化输出」的模型不会出现在要求 JSON Schema 的节点下拉里。」
  3. 登记时能力是空数组 → 显示空列表而不是报错
- 失败判定：空数组时崩掉
- 补充：**验证那句说明是真的**——登记一个没有「结构化输出」能力的模型，
  去要求 JSON Schema 的节点下拉里看它在不在

### MDL-19 · ACP 说明块

- 类型：可解释性
- 操作：看详情底部
- 预期：
  1. 标题「ACP 不提供模型列表」
  2. 正文解释为什么要手工登记
  3. **文案是否过期**：正文里写「从 CLI 配置导入与连通性测试要等适配器接上（M3）」，
     而 M3 已交付、连通性测试已经能用 → 这半句过期了，是缺陷
- 失败判定：文案与实际能力不符

### MDL-20 · 分栏与分页

- 类型：功能
- 操作：同 [11](11-Agent角色.md) AGT-19、AGT-20
- 预期：分栏默认 262px（图纸值），可拖、可键盘调、双击复位；
  分页 50 条一页

### MDL-21 · 三问清点

- 类型：体验
- 操作：对这些做三问：
  模型 ID（想复制它）、凭据引用（想复制、想去钥匙串里看）、
  能力标签的每一项（想知道它是什么意思）、
  「延迟 N ms」（想知道是什么时候测的）、
  接入方式（想知道这一档怎么配）
- 重点：
  1. **凭据引用能复制吗**？用户要拿它去钥匙串里核对
  2. **「尚未测试」能点吗**？看到它的第一反应是「那就测一下」——
     旁边有测试按钮，但这行文字本身呢
  3. **哪些 Agent / 节点在用这个模型**？删除警告说会失效，
     界面上看得到引用方吗
