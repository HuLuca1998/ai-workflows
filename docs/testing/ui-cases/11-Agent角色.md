# 11 · Agent 角色

路由 `/agents`。图纸「05 Agent 角色」：250px 左栏 + 详情区四块。

三条产品规则在这一屏兑现：

1. **角色是被引用的，不是被复制的**——节点存的是角色 id，
   角色升级后引用它的节点一并生效。所以保存按钮叫「保存新版本」。
2. **权限由引擎强制**——`command=none` 的角色跑不了脚本节点，
   `file` 不是 `read-write` 的动不了 worktree，拦在**起进程之前**。
3. **模型下拉只列已启用的**——过滤在后端做。

> 这一屏与[提示词库](12-提示词库.md)、[模型](13-模型.md)是同构的
> （左栏 + 详情）。**三屏之间的一致性**由
> [F3 剧本 R2](personas/F3-前端代码审查.md) 与
> [F1 第一副眼镜](personas/F1-界面与体验.md)负责，这里只测本屏功能。

## 用例

### AGT-01 · 空态与内置角色

- 类型：功能
- 前置：全新库
- 操作：打开 `/agents`
- 预期：**记录实际情况**——有没有内置角色？
  - 有：列表里显示它们，标签是「内置」
  - 没有：显示空态那句话
- 失败判定：显示空态但实际有数据（读取失败被误显示成空态）

### AGT-02 · 新建角色

- 类型：功能
- 操作：
  1. 点左栏 `+`
  2. 观察表单
  3. 只填名称，不填角色 → 看「创建」按钮
  4. 填齐名称 + 角色 + 选模型 → 点「创建」
- 预期：
  1. 详情区变成表单，可访问名「新建角色」
  2. 字段：名称、角色（占位「例如：代码审查者」）、目标、性格与指令、Runtime、模型
  3. 必填不全时「创建」**禁用**
  4. 说明文字：「权限、工具白名单和输出契约建完再调 —— 新建时默认只读文件、不联网。」
  5. 创建后：新角色被选中，详情区显示它
- 失败判定：创建后详情区退回「选一个角色查看详情」
  （新建的角色按名字排序可能落在第二页，界面必须仍选中它）

### AGT-03 · 模型下拉在数据晚到时也能用

- 类型：边界
- 操作：刷新页面后**立刻**点「新建角色」（抢在 `model_list` 返回之前）
- 预期：
  1. 下拉先显示「正在读取模型…」
  2. 模型到了之后**自动选中第一个**
  3. 「创建」按钮从禁用变成可用
- 失败判定：下拉永远是空的、创建按钮永远禁用

### AGT-04 · 一个模型都没登记时

- 类型：边界
- 前置：模型页里一条都没有
- 操作：点「新建角色」
- 预期：模型下拉显示「先去「模型」页登记一个」
- 失败判定：显示「正在读取模型…」卡住（那会让用户干等）

### AGT-05 · 模型下拉只列已启用的

- 类型：功能 / 可解释性（**核心规则**）
- 操作：
  1. 去模型页停用一个模型
  2. 回来打开某个角色的模型下拉
- 预期：被停用的**不在下拉里**
- 失败判定：还能选到停用的模型

### AGT-06 · 引用了已停用模型的角色

- 类型：边界（**这条很重要**）
- 操作：
  1. 某个角色绑着模型 A
  2. 去模型页停用 A
  3. 回来看这个角色的模型下拉
- 预期：
  1. 下拉里**保留** A，并标注「（已停用或已删除）」
  2. **不能悄悄跳到第一项**——那会让用户以为已经改绑了
- 失败判定：下拉自动选了别的模型

### AGT-07 · 编辑并保存新版本

- 类型：功能
- 操作：改名称、目标、性格，点「保存新版本」
- 预期：
  1. 保存成功
  2. 副标题的版本号 **+1**
  3. 左栏条目上的「vN」跟着变
  4. 只发送**真正改过的字段**（网络面板看请求体，
     不该是全量回写——那会覆盖并发的其他改动）
- 失败判定：版本号不变；或请求体里带了没改的字段

### AGT-08 · 没有改动时保存

- 类型：边界
- 操作：不改任何东西直接点「保存新版本」
- 预期：显示「没有改动可保存。」，**不产生新版本**
- 失败判定：每点一次就 +1 个版本

### AGT-09 · 权限四项可改，且引擎真的按它办事

- 类型：功能 / 安全（**核心承诺**）
- 操作：
  1. 把某个角色的「命令」设成「不允许」→ 保存新版本
  2. 用这个角色跑一条含**脚本节点**的工作流
- 预期：
  1. 四个下拉的选项与上表一致，显示的是**中文**
  2. 保存后再打开，值还在
  3. **脚本节点跑不起来**——被拦在起进程**之前**
     （拦晚了脚本已经写了文件才报错）
  4. 事件流里说清是权限拦的
- 失败判定：界面能选而引擎不拦（**假的安全感，比没有更糟，
  抄送 [B3 剧本 S1](personas/B3-安全与可解释性.md)**）

### AGT-10 · 文件权限与 worktree

- 类型：安全
- 操作：把「文件」设成「只读」→ 用它跑含 Git worktree 节点的工作流
- 预期：动不了 worktree，被拦下
- 失败判定：照样建了 worktree

### AGT-11 · 网络权限与 PR

- 类型：安全
- 操作：把「网络」设成「不允许」→ 用它跑会发 PR 的工作流
- 预期：发不出去，被拦下
- 失败判定：PR 发出去了

### AGT-12 · 工具白名单增删

- 类型：功能
- 操作：加两个工具名，删掉一个，保存
- 预期：
  1. 加的立刻出现在列表里
  2. 删的立刻消失
  3. 保存后刷新，结果一致
  4. 加**重复的名字**时的行为记录下来
- 失败判定：加了没保存上

### AGT-13 · 输出契约

- 类型：功能
- 操作：填一段输出契约，保存
- 预期：保存成功；没填时显示「未声明」
- 失败判定：显示 `undefined`

### AGT-14 · 复制角色

- 类型：功能
- 操作：选一个角色 → 点「复制」
- 预期：
  1. 出现一个新角色，名字是「<原名> 副本」
  2. 配置与原角色相同
  3. 副本**不是内置**（可编辑、可删除）
- 失败判定：副本仍标记为内置

### AGT-15 · 内置角色不能删

- 类型：功能 / 安全
- 操作：选一个内置角色
- 预期：
  1. **没有**「删除」按钮
  2. 显示提示「内置角色不能删除。要改的话先复制一份 —— 副本是可编辑的。」
  3. 按提示复制一份，副本**能删**
- 失败判定：内置角色有删除按钮

### AGT-16 · 删除的二次确认

- 类型：功能 / 边界
- 操作：
  1. 选一个非内置角色 → 点「删除」
  2. 观察
  3. 不点确认，改去选另一个角色，再选回来
  4. 点「删除」→ 点「确认删除」
- 预期：
  1. 按钮变成「确认删除」
  2. 出现警告「删除后引用它的节点会失效，而用户往往意识不到某个节点在用它。确认删除吗？」
  3. **切换角色后确认态被清掉**（再回来不是停在「确认删除」）
  4. 确认后角色消失
- 失败判定：确认态残留——用户在别的角色上点一下就删错了

### AGT-17 · 删除被引用的角色

- 类型：边界
- 操作：某个节点引用了角色 A → 删掉 A → 打开那条工作流
- 预期：
  1. 界面上能看出那个节点的角色**失效了**
  2. 校验或 Dry Run 会报出来，不是跑到一半才发现
- 失败判定：静默失效，跑起来才报一个看不懂的错

### AGT-18 · 搜索

- 类型：功能
- 操作：输入角色名的一部分，不按回车，等 1 秒
- 预期：
  1. 输入即搜（300ms 防抖），回车立刻搜
  2. 搜索发给**后端**（138 条角色时前端过滤只能过滤当前页）
  3. 搜完回到第 1 页
- 失败判定：只能回车搜；或只过滤了当前页

### AGT-19 · 分页

- 类型：功能 / 边界
- 前置：≥60 个角色
- 预期：每页 50 条，范围文字正确
- 补充：量分页控件的可发现性（左栏是独立滚动区）

### AGT-20 · 分栏可拖动

- 类型：功能 / 无障碍
- 操作：
  1. 拖动分隔条改宽度
  2. 刷新页面
  3. 用键盘：Tab 到分隔条，按左右方向键
  4. 双击分隔条
- 预期：
  1. 宽度跟手，有上下限（约 200–560px），拖不到 0
  2. 刷新后宽度**记住了**（localStorage）
  3. 方向键每次调一小步
  4. 双击**复位到 250px**（图纸值）
  5. 分隔条有 `role="separator"` + `aria-valuenow/min/max`
- 失败判定：能拖到 0 导致左栏消失且找不回来

### AGT-21 · 角色被引用而非复制

- 类型：可解释性（**核心规则**）
- 操作：
  1. 某个 AI 节点引用角色 A（v1）
  2. 改 A 的性格 → 保存新版本（v2）
  3. 跑那条工作流
- 预期：
  1. 节点用的是 **v2**（角色升级后引用它的节点一并生效）
  2. 运行记录里能追溯到用的是哪一版
- 失败判定：节点还在用 v1 的内容（说明是复制不是引用）

### AGT-22 · 三问清点

- 类型：体验
- 操作：对这些做三问：
  左栏条目的「vN」标签（想点它看版本历史）、
  副标题里的 runtime、Turn 上限（只读，想改怎么办）、
  权限说明「引擎强制，Prompt 无法越权」（想知道具体怎么强制的）、
  工具白名单里的每一项（想点它看那个工具是什么）
- 重点：
  1. **角色有版本历史可看吗**？提示词库有「版本」tab，这里有吗？
     没有的话，「保存新版本」保存到哪去了、怎么回滚？
  2. **哪些节点在用这个角色**？删除警告说「用户往往意识不到某个节点在用它」——
     那界面上有没有地方能看到引用方？
