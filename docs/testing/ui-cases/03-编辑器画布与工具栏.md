# 03 · 编辑器画布与工具栏

路由 `/editor/:workflowId`。图纸「02 画布编辑器」。

这一屏是这个产品最重的交互：拖放、连线、框选、缩放、右键。
**用户反馈过「拖动节点有点卡」——流畅度测量在 [F2 剧本 P1](personas/F2-交互健壮性.md)，
这里只测功能对不对。**

节点配置弹层见 [04](04-节点配置弹层.md)，右键菜单见 [05](05-右键菜单与分组.md)，
版本抽屉见 [06](06-版本发布与导入导出.md)，运行表单见 [07](07-启动表单与DryRun.md)。

## 元素清单

### 工具栏（高 50px）

| #   | 元素         | 内容                                           | 能点吗         | 点了应该怎样             |
| --- | ------------ | ---------------------------------------------- | -------------- | ------------------------ |
| 1   | 返回箭头     | `ph-arrow-left`，`aria-label="返回工作流列表"` | 应可点         | 去 `/`                   |
| 2   | 工作流名称   | `<h1>`，`title="双击改名"`                     | **双击**可改名 | 变成输入框               |
| 3   | 草稿标签     | 「草稿 · 基于 vN」或「草稿 · revN」            | 纯展示         | —                        |
| 4   | 撤销         | `aria-label="撤销（待实现）"`                  | **禁用**       | 有意如此                 |
| 5   | 重做         | `aria-label="重做（待实现）"`                  | **禁用**       | 有意如此                 |
| 6   | 校验状态     | 「校验通过 · N 节点 N 连接」或「N 个问题 · …」 | **待验证**     | 用户会想点它跳到问题节点 |
| 7   | 「版本」按钮 | 时钟图标                                       | 应可点         | 开/关版本抽屉            |
| 8   | 保存按钮     | 有改动时「保存草稿」，否则「已保存」（禁用）   | 应可点         | 提交草稿                 |
| 9   | 「发布版本」 | 有错误时禁用                                   | 应可点         | 发布新版本               |
| 10  | 「运行」     | 主按钮；有未保存改动或有错误时禁用             | 应可点         | 开启动表单               |

### 节点库（左栏 186px，`aria-label="节点库"`）

| #   | 元素     | 内容                                      | 能点吗     |
| --- | -------- | ----------------------------------------- | ---------- |
| 11  | 标题     | 「节点库 · 拖入画布」                     | 纯展示     |
| 12  | 搜索框   | 占位「搜索节点」，`aria-label="搜索节点"` | 应可输入   |
| 13  | 节点条目 | 图标 + 名称 + 拖动手柄；`role="button"`   | **可拖拽** |
| 14  | 空结果   | 「没有匹配的节点」                        | 纯展示     |

**16 种节点类型**（节点库展示 15 条，脚本合并成一条后展开成两项）：

AI · 分析 / AI · 审查 / AI · 决策 / AI · 执行 / 入口设置 / 调用子工作流 /
条件分支 / 数据转换 / 结束 / 人工审批 / 系统通知 /
Shell 脚本 / Python 脚本 / Git worktree / 环境变量 / MCP 工具

### 画布

| #   | 元素       | 说明                                            | 交互                      |
| --- | ---------- | ----------------------------------------------- | ------------------------- |
| 15  | 背景       | 点阵，间距 22px                                 | 右键出画布菜单            |
| 16  | 节点       | 210×66，三种色调，`.wf-node`                    | 拖动 / 双击 / 右键 / 框选 |
| 17  | 节点连接点 | 左·上是输入，右·下是输出（`cursor: crosshair`） | 拖出连线                  |
| 18  | 连线       | 节点之间                                        | 右键出连线菜单            |
| 19  | 分组虚线框 | 带标题                                          | 右键出分组菜单            |
| 20  | 空画布提示 | 「从左侧拖入入口节点」                          | 纯展示                    |
| 21  | 缩放控件   | 放大 / 缩小 / 适应视图 / 百分比                 | 应可点                    |
| 22  | 状态栏     | 见下                                            | 纯展示                    |

状态栏五段（一字不差）：
`双击编辑 · 右键菜单` · `端口拖出连线 · 点连线可删` · `Shift 框选 · ⌘A 全选` ·
`已选 N 个`／`未选中` · `N 节点 N 连接`

## 用例

### EDT-01 · 不带 id 进来给引导

- 类型：功能
- 操作：访问 `/editor`
- 预期：标题「工作流编辑器」+ 正文「先在**概览与工作流**里选一个工作流，或新建一个。」，
  其中「概览与工作流」是链接
- 失败判定：显示空画布

### EDT-02 · 打开一条已有工作流

- 类型：功能
- 前置：一条有节点的工作流
- 操作：从 `/` 点它的行
- 预期：
  1. 先出现「正在读取草稿…」，然后画布渲染
  2. 工具栏显示正确的名称
  3. 画布**自动适配视图**，所有节点可见
  4. **缩放不超过 100%**（fitView 上限压到 1，头几个节点挨得近时不该放大到 220%）
  5. 状态栏的「N 节点 N 连接」与实际数量一致
- 失败判定：打开就是 220% 缩放、节点重叠溢出

### EDT-03 · 节点库 16 种类型齐全

- 类型：功能
- 操作：数节点库的条目
- 预期：
  1. 共 16 条可拖条目（脚本那条展开成「Shell 脚本」与「Python 脚本」）
  2. 名称与上面的清单一致
  3. AI 类节点的图标有区分标记（`data-ai`）
  4. 每条悬停有 `title`，显示该类型的简介
- 失败判定：少于 16 条；名称对不上

### EDT-04 · 节点库搜索

- 类型：功能 / 边界
- 操作：
  1. 输入「脚本」
  2. 清空，输入「AI」
  3. 清空，输入「zzz」
- 预期：
  1. 只剩两条脚本
  2. 剩四条 AI 节点
  3. 显示「没有匹配的节点」
  4. 搜索是**本地过滤**，不发请求
- 失败判定：搜索不区分大小写失效；空结果时列表空白无提示

### EDT-05 · 拖一个节点到画布

- 类型：功能
- 操作：把「入口设置」从节点库拖到画布中央
- 预期：
  1. 拖动过程中光标是 move
  2. 松手后节点出现在**鼠标落点**（节点中心对准鼠标，不是左上角）
  3. 节点标题是「入口设置」
  4. 状态栏「N 节点」+1
  5. 保存按钮从「已保存」变成「保存草稿」（dirty）
  6. 空画布提示「从左侧拖入入口节点」消失
- 失败判定：节点落在别处；落点偏移一个节点的宽高

### EDT-06 · 刚拖进来的节点校验不通过是对的

- 类型：功能 / 体验
- 操作：拖一个「Shell 脚本」节点进来
- 预期：
  1. 工具栏校验状态变成「N 个问题 · …」（不是「校验通过」）
  2. 该节点在画布上有问题标记（`data-issue="true"`）
  3. 「运行」按钮禁用
- 说明：必填项填的是明显的占位（如「# 待填写命令」），
  **这是有意的**——给一个「看起来能跑」的假配置会让人以为不用配。
- 失败判定：拖进来就显示「校验通过」

### EDT-07 · 连线

- 类型：功能
- 前置：画布上有 entry 与一个脚本节点
- 操作：从 entry 节点的**右侧连接点**按住拖到脚本节点的**左侧连接点**
- 预期：
  1. 拖动过程中有连线预览
  2. 松手后连线建立
  3. 状态栏「N 连接」+1
  4. 变成 dirty
- 失败判定：连不上；连上了但状态栏没变

### EDT-08 · 不合法的连线方向被拒

- 类型：边界
- 操作：
  1. 尝试从「结束」节点的输出端拖出连线
  2. 尝试连到「入口设置」节点的输入端
- 预期：连不上（端口不存在的方向本来就不该连），且**不报错、不产生半条边**
- 失败判定：连上了；或弹出错误

### EDT-09 · 拖动节点只在松手时落库

- 类型：功能 / 性能
- 操作：拖一个节点绕圈 3 秒再松手
- 预期：
  1. 拖动过程中**不发请求**（`workflow_save_draft` 一次都不发）
  2. 松手后草稿更新（dirty 变化）
  3. 拖动过程中不产生几十个修订
- 失败判定：拖动时每帧都发请求

### EDT-10 · 框选与 ⌘A 全选

- 类型：功能
- 前置：画布上 ≥3 个节点
- 操作：
  1. 在空白处按住拖出一个矩形框住 2 个节点
  2. 点空白取消选中
  3. 按 ⌘A
- 预期：
  1. 框选后状态栏显示「已选 2 个」，被选节点有选中样式
  2. 取消后显示「未选中」
  3. ⌘A 后显示「已选 <全部节点数> 个」
- 失败判定：⌘A 无效（状态栏承诺了就必须能用）

### EDT-11 · 在输入框里按 ⌘A 是全选文本

- 类型：边界
- 操作：
  1. 双击工作流名称进入改名输入框
  2. 按 ⌘A
- 预期：选中的是输入框里的文字，**画布节点没有被全选**（状态栏仍是「未选中」）
- 失败判定：画布全选了——改名时想全选文字却选中整张图

### EDT-12 · 删除选中节点

- 类型：功能
- 操作：选中一个节点，按 Delete（或 Backspace）
- 预期：
  1. 节点消失
  2. 与它相连的边**一并消失**
  3. 状态栏节点数与连接数都变了
  4. 变成 dirty
- 失败判定：节点没了但边还在（悬空边）

### EDT-13 · 缩放控件四个按钮

- 类型：功能
- 操作：依次点放大、缩小、适应视图、百分比数字
- 预期：
  1. 放大 / 缩小按步进改变缩放，百分比数字跟着变
  2. 「适应视图」把所有节点框进视口
  3. 点百分比数字**复位到 100%**（`aria-label="缩放复位到 100%"`）
  4. 每个按钮都有 `aria-label`（放大 / 缩小 / 适应视图 / 缩放复位到 100%）
- 失败判定：百分比不跟着变；点数字没反应

### EDT-14 · 缩放上下限

- 类型：边界
- 操作：连续点缩小到底，再连续点放大到底
- 预期：下限 **35%**，上限 **220%**，到限后再点不变化
- 失败判定：能缩到 10% 或放到 500%

### EDT-15 · ⌘ + 滚轮缩放、滚轮平移

- 类型：功能
- 操作：
  1. 光标停在某个节点上，按住 ⌘ 滚动滚轮
  2. 松开 ⌘，直接滚动滚轮
- 预期：
  1. 以**光标位置**为中心缩放（不是画布中心）
  2. 不按 ⌘ 时是平移画布
- 失败判定：滚轮直接缩放（会让用户在滚页面时误缩放）

### EDT-16 · 保存草稿

- 类型：功能
- 操作：拖一个节点 → 点「保存草稿」
- 预期：
  1. 按钮进入 loading
  2. 成功后文字变成「已保存」并**禁用**
  3. 草稿标签的 rev 号 +1（若没有已发布版本，显示「草稿 · revN」）
- 失败判定：保存后按钮还是「保存草稿」；rev 没变

### EDT-17 · 未保存时刷新会被拦

- 类型：边界
- 操作：拖一个节点（不保存）→ 按 ⌘R 刷新
- 预期：浏览器弹出「离开此网站？」这类通用确认
- 说明：浏览器不允许自定义文案，只要弹出即可。
- 失败判定：直接刷新，改动无声消失，而工具栏还显示「已保存」

### EDT-18 · 站内跳走再回来，改动还在

- 类型：功能 / 边界
- 操作：拖一个节点（不保存）→ 点侧栏「执行记录」→ 浏览器后退
- 预期：改动**仍在**（编辑器只在 workflowId 变化时重建草稿）
- 失败判定：改动没了

### EDT-19 · 双击改名

- 类型：功能
- 操作：
  1. 双击工作流名称
  2. 输入新名字，按回车
  3. 再双击，改一个名字，按 Esc
  4. 再双击，清空内容，点别处（失焦）
- 预期：
  1. 变成输入框且自动聚焦，`aria-label="工作流名称"`
  2. 回车提交，标题变成新名字；回到 `/` 列表里也是新名字
  3. Esc 取消，名字不变
  4. 空名字**不提交**（当作没发生），不产生一条审计记录
- 失败判定：空名字被提交，列表里出现无名工作流

### EDT-20 · 校验状态随图变化

- 类型：功能
- 操作：
  1. 从合法的图开始（显示「校验通过 · N 节点 N 连接」）
  2. 删掉 entry 节点
  3. 撤销不了，就再拖一个回来
- 预期：
  1. 删掉后立刻变成「N 个问题 · N 节点 N 连接」，图标从对勾变成警告
  2. 「发布版本」与「运行」按钮禁用
  3. 补回来后恢复「校验通过」
- 失败判定：校验不实时；或有错误时仍能点发布

### EDT-21 · 运行按钮的两种禁用原因要说清

- 类型：体验
- 操作：
  1. 拖一个节点不保存 → 悬停「运行」
  2. 保存后，制造一个校验错误 → 悬停「运行」
- 预期：
  1. 第一种 title 是「有未保存的改动。先保存草稿再运行」
  2. 第二种 title 是「图有错误，先修好再运行」
- 失败判定：禁用但没有任何说明

### EDT-22 · 保存冲突时给得出脱身的路

- 类型：边界
- 操作：按 [F2 剧本 X5](personas/F2-交互健壮性.md) 制造两个标签页的冲突
- 预期：
  1. 后保存的那个显示错误条
  2. 错误条上有「放弃本地改动」按钮
  3. 点它 → 回到服务端那份图，错误消失，dirty 清掉
- 失败判定：报错但没有出路，只能刷新

### EDT-23 · 审批横幅

- 类型：功能
- 前置：这条工作流有一个运行卡在「等待审批」
- 操作：打开它的编辑器
- 预期：
  1. 工具栏与画布之间出现横幅（`role="status"`）
  2. 内容形如：**<节点名>** 正在等待你的决定 · 已等待 2 分 11 秒 · <摘要>
  3. 「已等待」的秒数**每秒跳一次**
  4. 右侧有两个链接：「查看 Diff」→ `/runs?run=<id>&tab=artifacts`；
     「处理审批」→ `/runs?run=<id>`
  5. 不满一分钟时只说秒（「43 秒」而不是「0 分 43 秒」）
- 失败判定：秒数不动（用户会以为界面卡了）

### EDT-24 · 空画布的提示

- 类型：体验
- 操作：新建一条空工作流
- 预期：画布中央显示「从左侧拖入入口节点」，拖入第一个节点后消失
- 失败判定：空画布什么都不说

### EDT-25 · 状态栏五段一字不差

- 类型：功能 / 体验
- 操作：截图状态栏，逐段比对
- 预期：
  `双击编辑 · 右键菜单` / `端口拖出连线 · 点连线可删` / `Shift 框选 · ⌘A 全选` /
  `已选 N 个`（未选中时是「未选中」）/ `N 节点 N 连接`
- 说明：状态栏上写的每一条**都是承诺**，逐条实测：
  双击真的能编辑吗？右键真的有菜单吗？点连线真的能删吗？
  Shift 框选真的可以吗？⌘A 真的全选吗？
- 失败判定：任何一条承诺不成立

### EDT-26 · 三问清点

- 类型：体验
- 操作：对这些元素做三问并交表：
  校验状态文字（#6，「3 个问题」——用户想点它跳到问题节点）、
  草稿标签「基于 vN」（想点它看那个版本）、
  画布节点上的徽标、连线本身、分组框标题、
  状态栏的「已选 N 个」与「N 节点 N 连接」
- 说明：校验状态那条最典型——用户看到「3 个问题」的第一反应是点它。
  点不动的话，他要怎么找到那三个问题在哪？
