主链路“拖节点 → 连线 → 配置 → 保存 → 发布 → 运行 → 看事件”可以完成，但日常辨认/对比运行、失败重试以及 Agent/提示词管理目前走不通。与 `docs/design/client/AI Workflows 客户端.dc.html` 的关键偏差集中在：概览统计值缺失、工作流状态不更新、执行记录缺工作流名/版本、编辑器自动缩放失控，以及图纸声明可编辑/可管理的 Agent 与提示词界面实际不可操作。
