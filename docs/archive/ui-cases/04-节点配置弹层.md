# 04 · 节点配置弹层

双击画布上的节点打开，760px。图纸「02 画布编辑器」的弹层。

这一屏的核心承诺是：**表单完全由 Schema 驱动，新增节点类型不改 UI 代码**。
所以你要测的不只是「能不能填」，还有「16 种节点类型都渲染得出来吗」。

## 元素清单

### 头部

| #   | 元素     | 内容                            | 能点吗   |
| --- | -------- | ------------------------------- | -------- |
| 1   | 类型图标 | 跟着节点类型变                  | 纯展示   |
| 2   | 标题输入 | `aria-label="节点标题"`，可编辑 | 应可输入 |
| 3   | 类型说明 | 「<类型名> · <一句话简介>」     | 纯展示   |
| 4   | 关闭     | `aria-label="关闭配置"`         | 应可点   |

### 四个 tab（`role="tablist"`）

`配置` · `输入 / 输出` · `权限与能力` · `重试与超时`

右侧常驻一行小字：「改动只影响草稿」

### 底部

| #   | 元素               | 状态                                                     |
| --- | ------------------ | -------------------------------------------------------- |
| 5   | 说明               | 「改动保存到草稿，不影响已发布版本」                     |
| 6   | 「取消」           | 可点                                                     |
| 7   | 「测试运行此节点」 | **禁用**，title「单节点试运行需要执行引擎，M2 阶段接入」 |
| 8   | 「保存到草稿」     | 主按钮                                                   |

> 第 7 项的 title 提到 M2，而 M2 已交付——这条文案是否过期，
> 在 CFG-14 里判定。

### 七种 Schema 控件

| 控件        | 长什么样                       | 出现在哪种字段             |
| ----------- | ------------------------------ | -------------------------- |
| `text`      | 单行输入                       | 大多数字符串               |
| `text-long` | 5 行文本域                     | 脚本正文、指令             |
| `number`    | 数字输入                       | 超时、上限                 |
| `boolean`   | 开关 + 「开启」/「关闭」文字   | 布尔                       |
| `enum`      | 下拉；非必填时首项是「未设置」 | 解释器、触发方式           |
| `list`      | chips + 末尾「+」输入框        | 字符串数组（工具白名单等） |
| `key-value` | 键值对表格 + 「+ 添加一项」    | `Record<string,string>`    |
| `json`      | 等宽文本域，解析失败时提示     | 对象数组、任意 JSON        |

每个字段：标签（必填带 `*`）· 控件 · 提示文字 · 错误文字（`role="alert"`）。

## 用例

### CFG-01 · 双击节点打开弹层

- 类型：功能
- 操作：双击画布上任一节点
- 预期：
  1. 弹层出现，`role="dialog"` `aria-modal="true"`，
     可访问名是「配置 <节点标题>」
  2. 宽度 760px
  3. 默认停在「配置」tab
  4. 标题输入框里是该节点的标题
  5. 类型说明显示该类型的名称与简介
- 失败判定：单击就打开（应该是双击）；打开的是别的节点

### CFG-02 · 16 种节点类型都能渲染出配置表单

- 类型：功能（**这条最重要**）
- 操作：把 16 种节点各拖一个进画布，逐个双击打开「配置」tab
- 预期（每一种都要满足）：
  1. 表单渲染出来，**不是空白**
  2. 每个字段有**中文标签**（不是英文字段名如 `agentProfileId`）
  3. 必填字段带 `*`
  4. 控件类型与字段语义匹配（脚本正文是多行、超时是数字、解释器是下拉）
  5. 有 `describe` 的字段下方显示提示文字
- 失败判定：某个类型渲染出空表单；标签显示成字段名（说明 Schema 缺 `.describe()`）
- 交表：

  | 节点类型 | 字段数 | 标签都是中文吗 | 控件类型正确吗 | 备注 |
  | -------- | ------ | -------------- | -------------- | ---- |

### CFG-03 · 七种控件逐个验证

- 类型：功能

| 控件      | 在哪试                   | 怎么试                                     | 预期                                           |
| --------- | ------------------------ | ------------------------------------------ | ---------------------------------------------- |
| text      | 任意字符串字段           | 输入、清空                                 | 值跟手                                         |
| text-long | Shell 脚本的「脚本」     | 输入多行                                   | 5 行高，可滚动，换行保留                       |
| number    | 脚本的「超时」           | 输入 1000、清空、输入 `abc`                | 清空得到未设置；`abc` 不能变成 NaN             |
| boolean   | 带布尔的类型             | 点开关                                     | 文字在「开启」/「关闭」之间切换                |
| enum      | 脚本的「解释器」         | 展开下拉                                   | 选项齐全；**非必填时有「未设置」空项**         |
| list      | MCP 工具的「工具白名单」 | 输入一项按回车；再输一项**不按回车点别处** | 两项都被加进去（onBlur 也生效）                |
| list      | 同上                     | 点某个 chip 的 ×                           | 该项移除，`aria-label="移除 <值>"`             |
| key-value | 带 Record 的类型         | 点「+ 添加一项」，填键与值                 | 键的 `aria-label` 是「键 1」，值是「值 1」     |
| key-value | 同上                     | 把键清空                                   | 该项被丢弃（不产生空键）                       |
| json      | 数据转换的「映射」       | 输入合法 JSON                              | 无错误                                         |
| json      | 同上                     | 输入 `{坏的`                               | 显示「JSON 无法解析：…」且**保留你输入的文本** |

- 失败判定：json 控件在解析失败时把用户输入清空了（那是丢数据）

### CFG-04 · 保存到草稿

- 类型：功能
- 操作：改一个字段 → 点「保存到草稿」
- 预期：
  1. 弹层关闭
  2. 画布上该节点的副文本跟着变（如果那个字段是摘要来源）
  3. 工具栏变成 dirty（「保存草稿」可点）
  4. 校验状态可能从「N 个问题」变成「校验通过」
- 失败判定：保存了但画布没变；或直接落库了（应该只进草稿）

### CFG-05 · 校验失败时逐字段回显中文错误

- 类型：功能 / 体验
- 操作：把某个必填字段清空 → 点「保存到草稿」
- 预期：
  1. **弹层不关闭**
  2. 自动切回「配置」tab
  3. 出错的字段下方出现红色错误文字（`role="alert"`）
  4. 错误文字是**中文**，不是 Zod 默认的英文
     （不能是 `Too small: expected string to have >=1 characters`）
  5. 字段容器有 `data-invalid="true"`
- 失败判定：弹一句「保存失败」让人猜哪里不对；或显示英文错误

### CFG-06 · 改标题

- 类型：功能
- 操作：
  1. 在标题输入框改成「我的节点」→ 保存
  2. 再打开，把标题清空 → 保存
- 预期：
  1. 画布上节点标题变成「我的节点」
  2. 清空后保存**沿用原标题**（不产生无名节点），且不产生多余的 Diff 项
- 失败判定：出现空标题的节点

### CFG-07 · 取消不留痕

- 类型：功能
- 操作：改几个字段 → 点「取消」
- 预期：
  1. 弹层关闭
  2. 节点配置**没有变化**
  3. 工具栏没有变成 dirty
- 失败判定：取消了但改动还是进了草稿

### CFG-08 · Esc 关闭

- 类型：功能 / 无障碍
- 操作：
  1. 打开弹层，焦点在标题输入框，按 Esc
  2. 再打开，先点一下弹层空白处再按 Esc
- 预期：两次都关闭
- 说明：Esc 的监听挂在遮罩的 `onKeyDown` 上，**焦点不在弹层内时是否生效要实测**。
- 失败判定：某种焦点位置下 Esc 无效

### CFG-09 · 「输入 / 输出」tab

- 类型：功能
- 操作：切到第二个 tab
- 预期：
  1. 顶部显示「N 条入边 · M 条出边」，数字与画布上实际连线一致
  2. 多入边时副文本是「多入边：需要在画布上设置汇聚策略」，
     否则是「执行语义由连线决定」
  3. 右侧标注「只读 · 在画布上改连线」
  4. 列出每个输入端口与输出端口
  5. 每个输出端口右边给出引用写法，形如 `${<节点id>.<端口id>}`
  6. 底部说明提到「下游节点按字段引用这些输出」
- 失败判定：入边出边数字与画布对不上；引用写法拼错

### CFG-10 · 「权限与能力」tab

- 类型：功能 / 安全
- 操作：切到第三个 tab
- 预期：
  1. 标题「能力声明（由引擎强制，Prompt 无法越权）」
  2. 五行：文件 / 命令 / 网络 / 记忆 / 凭据
  3. 凭据一行**没有值时显示「未授予」**，有值时显示引用（**绝不是明文**）
  4. 有副作用的节点（脚本、worktree、MCP 工具、通知）显示警告：
     「这个节点会产生外部写操作，运行时必须由审批或决策结果授权，重试前会核对外部状态。」
  5. 底部说明提到扩大权限会让 Trusted Workflow 策略失效
- 失败判定：凭据显示明文（**阻塞级，抄送 B3**）

### CFG-11 · 「重试与超时」tab

- 类型：功能
- 操作：切到第四个 tab
- 预期：
  1. 四项：超时 / 重试次数 / 重试模型 · 降级 / 幂等策略
  2. 超时显示「N min（墙钟）」；该类型没有超时设置时显示
     「该节点类型无超时设置」
  3. 重试次数默认「1 次 · exponential」
  4. 降级默认「保持同模型」
  5. 幂等默认「副作用操作重试前检查外部状态」
  6. 全部是**只读展示**
- 失败判定：显示 NaN 或 undefined

### CFG-12 · 四个 tab 之间切换不丢改动

- 类型：边界
- 操作：
  1. 在「配置」tab 改一个字段
  2. 切到「输入 / 输出」，再切回「配置」
- 预期：刚才改的值还在
- 失败判定：切 tab 把编辑中的值重置了

### CFG-13 · 极端输入

- 类型：边界
- 操作：对每种控件试[F2 剧本 X1](personas/F2-交互健壮性.md) 的七种输入
- 重点：
  1. 脚本正文粘贴 10 万字符 → 弹层布局不撑破，能保存或明确拒绝
  2. 标题输入 `<script>alert(1)</script>` → 保存后画布上**原样显示为文本**，不弹窗
  3. 数字字段输入 `1e999`、`-1`、小数
  4. list 控件加 50 项 → chips 换行不溢出
  5. key-value 加 30 行 → 弹层内可滚动，底部按钮**仍够得着**
- 失败判定：弹层被撑破导致按钮点不到；出现脚本执行

### CFG-14 · 「测试运行此节点」的文案是否过期

- 类型：体验 / 可解释性
- 操作：悬停底部的「测试运行此节点」按钮
- 预期：按钮禁用，title 说明为什么
- 判定：当前 title 是「单节点试运行需要执行引擎，M2 阶段接入」，
  而 **M2 已经交付**（见 `docs/ROADMAP.md`）。所以：
  - 如果引擎已能单节点试运行 → 按钮该启用，禁用是缺陷
  - 如果仍不能 → **文案过期**，是缺陷（用户按里程碑判断「什么时候有」）
- 同样的判定用于「重试与超时」tab 底部那句「重试策略的编辑要等引擎（M2）」

### CFG-15 · 弹层在矮窗口下底部按钮仍可达

- 类型：边界
- 操作：把窗口高度调到 500px，打开一个字段很多的节点（如 MCP 工具）
- 预期：内容区可滚动，底部三个按钮**始终可见或可滚到**
- 失败判定：按钮被挤出屏幕且滚不到

### CFG-16 · 焦点管理

- 类型：无障碍
- 操作：见 [F2 剧本 K3](personas/F2-交互健壮性.md)
- 预期：打开后焦点进入弹层、Tab 循环困在弹层内、Esc 关闭、
  关闭后焦点回到触发它的节点

### CFG-17 · 三问清点

- 类型：体验
- 操作：对这些做三问：类型说明文字、「改动只影响草稿」那行小字、
  输入/输出 tab 里的端口引用写法（用户会想**复制**它）、
  权限 tab 的五行能力、重试 tab 的四项只读值
- 重点：**端口引用写法 `${node.port}` 用户一定想复制**——
  有复制按钮吗？选中能复制吗？
