AI Workflows · 客户端功能文档与里程碑
v0.3 · macOS App + Web · 对应原型「AI Workflows 客户端」

本文覆盖客户端的全部菜单与功能细节，以及分阶段的开发里程碑。产品定位是本地优先的 AI Workflow 应用：把 AI 能力、脚本、人工审批、Git 隔离、通知与外部服务连成可复用的工作流，并让一个了解全软件能力的「主管 AI」协助设计、解释、优化与排障。

1. 产品原则

  • 可解释优先：任何时刻都能回答「现在跑到哪、为什么停、接下来做什么」。
  • 显式权限：读写文件、执行命令、访问网络、使用 Secret 都由策略控制，引擎强制，Prompt 无法越权。
  • 草稿与执行分离：编辑草稿不影响运行中的版本；运行记录永远引用不可变版本快照。
  • 结构化数据优先：节点之间按字段传递，文本拼接只是兼容方式。
  • AI 建议 ≠ 执行：AI 的修改一律先出 Diff，用户确认后才写入。
  • 本地优先与可恢复：工作流、记录、记忆、凭据留在本机；审批等待、重启、断网不丢 Run。
  • 拆分而非一次性：一个工作流就是一份计划；需要更细粒度就用子工作流拆开，每个子 Run 独立会话与环境快照。

3. 工作流编辑器

3.1 画布

  • 无边界画布：拖空白处平移、滚轮平移、⌘/Ctrl + 滚轮以光标为中心缩放（35%–220%），右上角 +/−/适应视图/百分比复位，进入时自动 fit。
  • 节点操作：拖动改布局（多选可整体移动）、双击打开配置、Delete 删除、右键菜单（编辑配置 / 复制 / 断开全部连线 / 建分组 / 删除）。
  • 连线：从节点右侧或底部端口拖出，自动选择最近端口对并绘制贝塞尔平滑曲线；点击选中连线，Delete 删除，右键可删除、反转方向、在连线上插入节点。
  • 选择：Shift 拖拽框选、⌘A 全选、Shift 点击加减选、Esc 取消；底部状态条实时显示选中数量与操作提示。
  • 分组区域：选中节点后右键「用选中节点建分组」，生成带标题的虚线框；右键分组可重命名或解散。
  • 执行语义由连线决定，不在节点里配置：1→N 并行分发、N→N 并行、N→1 阻塞汇聚，节点上以徽标显示（⋔3 / ⋀3）。

3.3 节点配置弹层

双击节点打开，四个标签页：配置（按节点类型渲染的表单，来自节点定义的 Schema）、输入 / 输出（端口与数据形状，顶部只读显示由连线推导的形态与入出边数）、权限与能力（能力声明、审批策略、脱敏规则）、重试与超时（超时、重试次数、降级、幂等与取消行为）。多入边节点额外出现汇聚策略：等待全部 / 任一先到 / Quorum / 按顺序、输入合并方式、部分失败处理、汇聚超时。

3.4 运行、版本与审批

  • 启动表单：选运行版本（已发布 vN / 当前草稿）、入口 Schema 自动生成的参数、工作目录与权限档、Dry Run 依赖检查、通知开关；草稿运行不产生版本快照。
  • 版本抽屉：草稿在顶部，历史版本带发布状态、变更摘要、被多少次运行引用；选中版本与草稿对比结构化 Diff；可导出、回滚为草稿、发布为新版本。
  • 审批呈现：画布节点脉冲高亮 + 顶部横幅（等待时长、变更摘要、快捷处理），完整决策表单在主管 AI 抽屉与执行记录中。

4. 主管 AI

  • 右侧抽屉，⌘K 呼出；左侧可折叠历史会话列表（按关联的工作流 / 运行 / 记忆 / 模型标注）。
  • 多轮对话：用户与 AI 消息、折叠的工具调用轨迹（workflow.get / search_nodes / patch / validate）、上下文 chips（草稿版本、选中节点、当前运行、生效记忆，可增删）、底部输入框显示轮次与上下文用量。
  • 全软件范围能力：解释流程、生成结构化 Patch、拆分子工作流、管理记忆、优化提示词并存版本、调整 Agent 与模型、检索运行事件找失败共因。
  • 安全边界：修改草稿必须先展示 Diff 并确认；发布、运行、删除、扩权需单独授权；抽屉底部常驻本次会话授予的 Scope。
  • 模型可随时切换，只列出「模型」页中已启用条目。

5. 执行记录

  • 三级结构：运行列表 → 节点列表 → 节点详情。
  • 运行列表：同一工作流可用不同参数并行运行，多个工作流亦可同时运行；分「并行进行中」与「历史」，带状态筛选与可恢复提示。
  • 节点列表：按连线拓扑排序显示执行顺序，扇出处插入「并行组」标题并缩进成员，汇聚节点标注等待策略；顶部为进度条、当前节点与剩余数量。
  • 节点详情按类型呈现：入口给启动快照与注入字段；脚本给命令、stdout / stderr、exitCode 与输出映射；分析 / 审查给产出文档表与结构化摘要；决策给分级判定与证据；执行给文件变更与验证输出；审批给请求内容、选项与决定 JSON；worktree 给 git 命令与写入的环境键。每个详情都可「在画布中定位 / 从此节点重试 / 复制脱敏记录」。
  • 运行概览：对话（面向理解的时间线 + 固定 composer 与遥测栏）、事件（九类分类事件流，右下角筛选器可按类别勾选并切换摘要 / 详细）、产物（Diff、报告、日志，可预览导出）。
  • 失败与恢复：失败横幅给出失败节点、错误分类、exitCode 与 stderr 摘要，并提供从失败节点重试、回到最近审批点改选择、用相同参数重跑、导出诊断包；未结束 Run 在列表顶部提示可恢复，并说明哪些上下文已变化。

6. 记忆、角色、提示词、模型

模块 功能
记忆 五种作用域（全局 / 工作区 / 工作流 / Agent / 会话）的增删改查；AI 提议写入区，确认后才保存；编辑抽屉含作用域、过期策略、标签、敏感级别与版本保护；Token 与密钥禁止写入；删除后不再注入。
Agent 角色 内置 Analyst / Builder / Reviewer / Operator / Workflow Designer，可复制修改；字段含角色、目标、性格与指令、Runtime（ACP Claude / ACP Codex / Provider API）、模型与降级、模型策略、工具与 MCP 白名单、文件 / 命令 / 网络 / 记忆 / 审批权限、输出契约、Turn 与超时上限、版本与引用计数。
提示词库 系统调用 AI 的每一处提示词集中管理：节点提示词与系统内建（流程解释、结构化 Patch、记忆提议、通知文案、失败归因）。框架分段可见可改（Role / Task / Context / Constraints / Output contract），变量表列出运行时来源与缺失处理，运行时预览用真实运行替换变量并可试跑，版本历史保证历史结果可解释；内置项可「恢复默认」。
模型 所有可用模型必须先登记，其它下拉只列已启用条目。按接入方式分组（ACP · Codex / ACP · Claude Code / HTTPS 兼容端点 / 自建网关），字段含模型 ID、推理档位（同一模型不同档位为不同条目）、上下文窗口、能力标签、凭据引用、延迟、计费、限流。ACP 握手不返回模型列表，因此提供从 CLI 导入与手动登记，并提醒 adapter 与 CLI 版本成对锁定。底部维护快速 / 均衡 / 高质量的策略映射。

7. 环境、安装与安全

  • 首次配置四步：设备与磁盘 → 工具与运行时 → ACP 探测 → 目录授权与运行示例。工具清单列出来源、版本、大小、安装位置与将执行的命令（不使用 sudo、不改 shell profile、不写全局 PATH）；ACP 探测依赖上一步完成，装完自动握手，只创建空 session。
  • 环境健康中心：Ready / Needs Attention 总览，每项能力的版本、路径、来源与状态，支持重新检查、Repair、导出脱敏报告。
  • 权限三档：Review Every Change / Workspace Safe / Trusted Workflow；权限扩大或版本重要变化时自动失效并重新确认。
  • 凭据：明文只进 macOS Keychain，数据库仅存引用；注入子进程后立即释放；stdout / stderr / AI 输入输出统一过脱敏器后才落库。

9. 验收标准（跨阶段）

  • 任何运行都能回答：用了哪个版本、哪些提示词版本、哪个模型、注入了哪些记忆、谁在什么时候批准了什么。
  • 所有外部写操作（push / PR / 发布 / 删除）都由审批或决策结果授权，重试前核对外部状态。
  • Secret 从不出现在事件、日志、预览与导出中；界面不提供绕过脱敏的入口。
  • 断电、退出、网络中断后重新打开，未结束的 Run 显示真实状态并可恢复。
  • 深色界面在 Increase Contrast 与 Reduce Motion 下仍可用；重要状态不只用颜色表达；1280×800 窗口下三栏可收起。

10. 首版非目标

  • 不兼容 Alfred Workflow 文件格式；不做团队云协作与多人实时编辑。
  • 不提供 Telegram / Discord 等全部外部通知渠道，首版只做 macOS 系统通知。
  • 不展示模型私有原始思维链，只展示面向用户的推理摘要、工具证据与结果。
  • 不承诺任意第三方命令自动静默安装；系统级依赖必须告知并授权。

13. 术语表

术语 含义
Workflow / Revision / Version 流程定义 / 可变草稿修订号 / 已发布的不可变快照
Run / RunEvent / Checkpoint 一次执行 / 唯一事实来源的事件 / 可恢复的执行断点
AgentProfile 可复用 AI 角色：性格、模型、权限、记忆范围、输出契约
迭代 / 子工作流 不设独立「计划」能力：一个工作流即一份计划，拆分靠子工作流，每个子 Run 独立会话与环境快照

迭代域 （已移除）改由子工作流表达
Scope MCP / API 的能力范围：workflow:read、write-draft、publish、run、memory:read/write

14. 给实现方的交付顺序建议
