## 文档约定

- 写清「为什么」，而不只是「是什么」——代码本身能说明是什么
- 决策写进 ADR，欠账写进 DEBT，排期写进 ROADMAP，规则写进 CONTRIBUTING / TESTING
- 相对日期一律换成绝对日期，方便半年后回看
- **文档里的每个数字都要可复现**。写「50 个工具」就得有一条命令能数出 50
