## 图纸与参考资料

| 目录                             | 内容                                                                                                  |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [design/client/](design/client/) | **设计图纸**：可交互原型、功能文档与里程碑、技术选型、Nocturne 设计系统。用浏览器打开 `.dc.html` 查看 |
| [reference/acp/](reference/acp/) | ACP（Agent Client Protocol）实战经验：协议生命周期、实测结论、踩坑清单、参考实现                      |

图纸是施工依据。实现与图纸不一致时，**先改文档或记一条 ADR，不要静默偏离**。

## 文档约定

- 写清「为什么」，而不只是「是什么」——代码本身能说明是什么。
- 决策写进 ADR，状态与进度写进 ROADMAP，规则写进 CONTRIBUTING / TESTING。
- 相对日期一律换成绝对日期，方便半年后回看。
