| 编号    | 原文怎么说                                            | 问题                                                                                                                                                                            | 实现怎么做                                                                                                                                                                      |
| ------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A-1** | §7「neutral-600 仅用于 ≥11px 的元信息」               | neutral-600 在 surface 上 **3.52:1**，而 WCAG 的 3:1 豁免只给大字（≥18.66px 常规 / ≥14px 粗体）。11px 远不够，何况它的用途是「**全大写小字**的分组标题」                        | 承载关键信息的文字一律 neutral-500（5.25:1）以上；600 只用于真正的装饰性元信息                                                                                                  |
| **A-2** | §5.3「普通连线用 neutral-700」                        | neutral-700 在 bg 上 **2.69:1**，低于 WCAG 对图形元素的 3:1 门槛，而连线只有 1.5px                                                                                              | 普通连线改用 neutral-600（4.08:1）                                                                                                                                              |
| **A-3** | §5.3 只规定了描边色/线宽/dash/动画                    | **完全没规定连线上的文字与标签**。而契约的 `GraphEdge` 带 `source.port`，branch 节点的配置是 `cases:[{port,when}]` —— 分支条件必须有地方显示                                    | 端口名按语义分色（success/approved 绿、failed/rejected 红、branch 的自定义 port 用 accent-300）；单输出端口时不标（纯噪声）；标签底色显式给 surface，否则走 XYFlow 的白色默认值 |
| **A-4** | §2.3「信息色 #4096b2 仅用于环境光，界面元素不使用」   | 「提示/说明」这类语义因此没有分配颜色                                                                                                                                           | 信息类一律用中性阶梯；该色只出现在 `--ambient-info` 里                                                                                                                          |
| **A-5** | 画布图纸的 `bez()` 用 `k = max(46, d*0.42)`，只有下限 | 弦长 40 时算出 k=46，两个相向的控制点越过彼此（c1.x=296 > c2.x=244），曲线在 t≈0.38–0.62 之间**倒退 1.485px**（路径长 42.97 vs 弦长 40 就是痕迹）。节点再靠近一点就是可见的回钩 | 再加一道 `d/2` 上限：`k = min(max(46, d*0.42), d/2)`。控制点最多在中点相遇，长边不受影响                                                                                        |
| **A-6** | 图纸的 `curve()` 直接在 16 组合里取最小距离           | 两节点**相贴**时 `A.right` 与 `B.left` 是不同 side 但同一个点，d=0 必然胜出 → 起终点重合、曲线钻进对面节点再穿回来；端口坐标重合的重叠布局直接得到闭环                          | 候选里排除同侧组合，以及端点间距 <1px 的组合                                                                                                                                    |

## 1. 设计原则

| 原则           | 含义与落地方式                                                                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 暗场 + 一束光  | 基色近黑蓝紫 `#161826`，全局只有一个强调色 `#9184d9`。光只出现在「需要人关注」处：等待审批、运行中、当前选中。其余保持中性。                                     |
| 状态即颜色     | 颜色不做装饰。紫=需要你或 AI 正在参与；绿=成功；黄=需要注意；红=失败或不可逆；中性灰=静态信息。**同一语义在全应用只有一种表达**。                                |
| 层次靠光不靠框 | 面板间用 1px 分隔线 + 极低对比表面色差；卡片用「上缘高光 + 下方投影」制造抬起感，避免大量描边造成噪声。                                                          |
| 动效服务于因果 | 动效只用于三处：状态在变化、数据在流动、用户刚做了操作。无纯装饰动画，无入场动画堆叠。                                                                           |
| 性能优先 8:2   | 不用大面积 `filter: blur()`、`backdrop-filter`、阴影动画、全屏循环动画。氛围光全静态渐变；动画只作用于小元素，且只动 `opacity`/`transform`/`stroke-dashoffset`。 |

## 2. 色彩体系

### 2.1 基础色

| 令牌              | 色值      | 用途                               |
| ----------------- | --------- | ---------------------------------- |
| `--color-bg`      | `#161826` | 窗口底色                           |
| `--color-surface` | `#232532` | 面板/卡片                          |
| `--color-text`    | `#e9e9ed` | 主文本（不用纯白，降眩光）         |
| `--color-divider` | text 16%  | 所有面板边界、表头下缘、列表行分隔 |
| `--color-accent`  | `#9184d9` | 唯一品牌色（OKLCH 色相 289.2）     |

### 2.2 强调色阶与使用位置

| 令牌             | 色值      | 使用位置                                                |
| ---------------- | --------- | ------------------------------------------------------- |
| `accent-200`     | `#e7e5fe` | 紫底之上的文字：选中导航项、审批横幅标题、等待节点标题  |
| `accent-300`     | `#d2cefd` | 次级紫文字：模型芯片、等待节点副标题、AI 会话中的工具名 |
| `accent-400`     | `#b5abfc` | AI 类节点图标、链接 hover                               |
| `accent`         | `#9184d9` | 指示点、连线高亮、选中外框、焦点环、进度条              |
| `accent-600`     | `#796cbf` | 悬停时的卡片描边、等待节点描边                          |
| `accent-700`     | `#5d5294` | 选中行描边、迭代/分组框描边                             |
| `accent-800/900` | `#423a6a` | 等待节点渐变底、标签底色、深紫容器                      |

### 2.3 语义状态色（仅用于状态，不进通用色阶）

| 语义       | 色值      | 底色（14%）             | 出现位置                                     |
| ---------- | --------- | ----------------------- | -------------------------------------------- |
| 成功       | `#7fb894` | `rgba(111,185,114,.14)` | 节点完成、测试通过、健康检查就绪、记忆已启用 |
| 注意       | `#dfb04a` | `rgba(223,176,74,.10)`  | 待安装/待登录、版本错配、等待依赖            |
| 失败/危险  | `#e0685c` | `rgba(224,104,92,.12)`  | 运行失败、右键菜单删除项、不可用模型         |
| 信息（辅） | `#4096b2` | —                       | **仅用于环境光第二色，界面元素不使用**       |

三色明度都压在 L≈0.72，与强调色同视觉重量。**只做文字色与 14% 底色，不做大面积填充**。

### 2.4 中性文字阶梯

| 令牌              | 色值      | 用途                                   |
| ----------------- | --------- | -------------------------------------- |
| `neutral-200/300` | `#cfd3e5` | 次级正文、菜单项、节点库标签           |
| `neutral-400`     | `#b2b6ca` | 未选中导航项、面包屑、说明文字         |
| `neutral-500`     | `#9397ab` | 字段说明、辅助描述                     |
| `neutral-600`     | `#75798c` | 分组标题（全大写小字）、时间戳、元信息 |
| `neutral-700/800` | `#595d6c` | 连线默认色、虚线描边、画布点阵、滚动条 |

**规则：一屏之内文字最多用到四档**（主文本 + 400 + 600 + 强调），再多会失去层级感。

### 2.5 允许的叠加层（穷举，不得新增）

```
rgba(233,233,237,.035)    表格行悬停
rgba(233,233,237,.045)    列表项悬停（统一值）
rgba(233,233,237,.06–.09) 中性芯片 / 分段控件 / 次级按钮底
rgba(145,132,217,.06–.13) 紫色选中底（渐变暗端）
rgba(145,132,217,.20–.30) 紫色选中底（渐变亮端）、审批横幅左端
rgba(255,255,255,.05–.07) 卡片上缘 1px 内高光
```

**悬停提亮统一 4.5%**——低于 3% 感知不到，高于 6% 暗场发白。

## 3. 明暗与层次（Elevation）

| 层级         | 配方                                                                                                 | 用于                             |
| ------------ | ---------------------------------------------------------------------------------------------------- | -------------------------------- |
| L0 底        | `--color-bg` + 两束静态环境光                                                                        | 窗口画布                         |
| L1 面板      | surface 12–42% 渐变 + 1px divider + `inset 1px 0 0 rgba(255,255,255,.03)`                            | 侧栏、节点库、列表列、设置分区   |
| L2 卡片      | surface 62→92% 竖向渐变 + 上缘内高光 + `0 10px 26px -12px rgba(0,0,0,.85)`                           | 画布节点、统计卡、事件卡         |
| L3 悬浮      | L2 + 描边转 accent-600 + `0 16px 34px -16px rgba(0,0,0,.95)` + `0 0 26px -10px rgba(145,132,217,.6)` | 节点悬停                         |
| L4 弹层      | surface 94–96% + neutral-700 描边 + `0 18px 44px rgba(0,0,0,.6)`                                     | 右键菜单、模型下拉、配置弹层     |
| L5 抽屉/模态 | surface 92% + `-24px 0 60px rgba(0,0,0,.55)` + **背景 35% 黑遮罩**（注意：不含 blur）                | 主管 AI 抽屉、记忆编辑、启动弹层 |

### 3.1 环境光配方（静态，零运行时成本）

```css
/* 窗口层 */
radial-gradient(58% 44% at 6% -6%, rgba(145,132,217,.30), transparent 62%),
radial-gradient(52% 42% at 104% 106%, rgba(64,150,178,.22), transparent 66%)
顶部 1px：linear-gradient(90deg,transparent,rgba(145,132,217,.7) 22%,rgba(255,255,255,.35) 50%,rgba(145,132,217,.7) 78%,transparent)

/* 画布层 */
radial-gradient(60% 50% at 26% 12%, rgba(145,132,217,.20), transparent 70%),
radial-gradient(55% 55% at 92% 96%, rgba(64,150,178,.16), transparent 72%),
radial-gradient(circle at 30% 20%, surface 34%, bg 82% 72%)
点阵：radial-gradient(color-mix(accent-600 45%, neutral-800) 1px, transparent 1px) / 22px, opacity .5
```

左上紫、右下青的对角布光让大面积暗场有方向感。青色**只作为环境光**，界面控件不出现。

### 3.2 窗口外框

```css
border-radius: 14px;
box-shadow:
  0 0 0 1px var(--color-neutral-800),
  0 1px 0 rgba(255, 255, 255, 0.07) inset,
  0 50px 120px -24px rgba(0, 0, 0, 0.9),
  0 0 100px -40px rgba(145, 132, 217, 0.5);
```

## 4. 动效规范

| 名称             | 时长/曲线                            | 作用对象                 | 目的                                |
| ---------------- | ------------------------------------ | ------------------------ | ----------------------------------- |
| 状态过渡         | 160ms ease                           | 背景色、文字色           | 悬停/选中不闪切                     |
| 描边与投影       | 180–200ms ease                       | border-color、box-shadow | 抬起感跟手                          |
| `dotrun`         | 1.6s 无限，opacity .25→1             | 6px 运行指示点           | 表示「仍在进行」                    |
| `waitpulse`      | 2.4s 无限，box-shadow 呼吸           | 等待审批的单个节点       | 全画布唯一强提醒；**同屏最多 1 个** |
| `flow`           | 1.1s linear，stroke-dashoffset 0→−40 | 活跃连线、AI 新增连线    | 表达数据流向与「这是提议」          |
| `rise / slidein` | 180/220ms ease-out                   | 弹层、抽屉入场           | 建立空间来源感，只播一次            |

### 4.1 硬性约束

- 循环动画同屏 **≤ 3 个**，且每个作用面积 < 220×70px
- 只动 `opacity`、`transform`、`stroke-dashoffset`、小元素的 `box-shadow`；**禁止动画 `width/height/top/left/filter`**
- 拖拽中的节点不加过渡（`left/top` 不参与 transition）
- **不使用 `backdrop-filter`**（仅标题栏可选，且面积 < 1440×44）；不使用大面积 `filter: blur()`
- 遵守 `prefers-reduced-motion`：关闭 dotrun/waitpulse/flow，**改为静态高亮**（不是简单抹掉动画）

## 5. 组件状态规范

### 5.1 统一四态

| 状态 | 配方                                                                                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 默认 | 透明底 + `1px solid transparent` 占位（避免选中时抖动）                                                                                                      |
| 悬停 | `background: rgba(233,233,237,.045)`，160ms 过渡                                                                                                             |
| 选中 | `border:1px solid var(--color-accent-700)` + `linear-gradient(90deg,rgba(145,132,217,.20),rgba(145,132,217,.06))` + `0 6px 18px -14px rgba(145,132,217,.95)` |
| 禁用 | `opacity:.45; cursor:not-allowed`，不改色相                                                                                                                  |

应用于：运行列表、执行记录节点列、Agent 列表、模型列表、提示词列表、版本列表。
**侧栏导航与设置分区改用左内侧 2px 强调条**（`inset 2px 0 0 var(--color-accent)`），因为它们是「位置」而非「数据行」。

### 5.2 画布节点

| 语义             | 视觉                                                                   |
| ---------------- | ---------------------------------------------------------------------- |
| 已完成           | L2 卡片 + 中性描边；右上角「完成」绿色小字                             |
| 等待中           | accent-800→900 渐变底 + accent-600 描边 + `waitpulse`；标题 accent-200 |
| 待运行           | surface 45% + 1px 虚线中性描边；文字降到 neutral-400                   |
| AI 提议（ghost） | accent-900 底 + 紫色虚线描边 + 6px 紫光晕；连线走 `flow` 虚线          |
| 选中             | 1.5px accent 外框（offset 3px）+ `0 0 30px -6px rgba(145,132,217,.85)` |
| 悬停             | 描边转 accent-600 + L3 阴影；**不位移**（位移会干扰连线判断）          |

### 5.3 连线

| 类型         | 描边                               | 说明                                   |
| ------------ | ---------------------------------- | -------------------------------------- |
| 普通         | neutral-700 · 1.5px 实线           | 静态，不发光                           |
| 指向等待节点 | accent · 1.8px · dash 5 5 · `flow` | 视线自然被引到待办                     |
| AI 提议      | accent · 1.8px · dash 6 4 · `flow` | 与「等待」用 dash 节奏区分             |
| 选中         | accent-300 · 2.4px                 | 另有 **14px 透明命中区**，便于点选删除 |

### 5.4 按钮与输入

- Primary = 强调色描边 + 文字，hover 叠 12% 强调底，active 22%；**不使用实心紫按钮**（避免与「等待」语义冲突）
- Secondary = divider 描边，hover 叠 7% 文字色。**危险操作只用红色文字 + 确认，不做红色实心按钮**
- 输入框 focus 用 `focus-visible` 2px 强调环，键盘可达；**不移除 outline**

## 6. 交互规范

| 交互          | 行为与反馈                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| 画布平移/缩放 | 拖空白平移；滚轮平移，⌘/Ctrl+滚轮以光标为中心缩放；缩放时点阵间距同步跟随                                 |
| 选择          | 点选、Shift 加减选、Shift 拖拽框选（紫色 12% 半透明矩形）、⌘A 全选；**底部状态条实时回报「已选中 N 个」** |
| 连线编辑      | 从端口拖出连线，落点高亮；点连线选中，Delete 删除；右键连线可删除/反转/插入节点                           |
| 右键菜单      | 四种上下文（节点/连线/分组/空白）；**危险项红字且置底**；点击遮罩或再次右键关闭                           |
| 节点配置      | 双击打开居中弹层，Esc 关闭；表单由节点 Schema 驱动                                                        |
| 审批          | 画布节点脉冲高亮 + 顶部横幅**双通道**；横幅左端紫光渐隐，操作按钮右对齐                                   |
| 主管 AI       | ⌘K 从右侧滑入抽屉（220ms）；历史会话列可折叠；上下文以 chips 呈现，可增删                                 |
| 反馈时延      | <100ms 立即态；100–1000ms 行内 spinner 或进度条；**>1s 必须给可取消的进度与阶段文字**                     |

## 7. 无障碍与密度

- 正文对比度 ≥ 4.5:1（neutral-400 以上用于正文，600 仅用于 ≥11px 元信息且不承载关键信息）
- **状态不能只靠颜色**：完成/等待/失败都同时带文字标签或图标
- 可点击区域最小 **28×28px**（桌面密度 2），列表行高 **34–42px**；触控形态升到 44px
- 焦点可见：所有可交互元素保留 `focus-visible` 2px 强调环

## 8. 性能预算

| 项目                   | 预算                                                   |
| ---------------------- | ------------------------------------------------------ |
| 同屏循环动画           | ≤ 3 个，合计动画面积 ≤ 屏幕 3%                         |
| blur / backdrop-filter | 禁止大面积；标题栏可选，单处 ≤ 64k px²                 |
| 阴影层数               | 单元素 ≤ 4 层，且不参与动画                            |
| 渐变层数               | 单元素 ≤ 3 个 radial/linear                            |
| 画布                   | 200 节点拖拽 ≥ 50fps；点阵用 background-image 而非 DOM |
| 长列表                 | > 300 行虚拟滚动；事件流按 seq 分页加载                |

## 9. 反面清单（明确不做）

- 不做全屏动态渐变、极光流动、粒子背景、扫描线循环
- 不做玻璃拟态堆叠（多层 backdrop-filter），不做霓虹描边发光文字
- 不做多品牌色渐变按钮，不做圆角容器 + 左侧色条的模板化卡片
- **不用 emoji 表示状态**，不用彩色图标做纯装饰
- **不在同一屏出现两个以上「呼吸/脉冲」元素**——注意力只能有一个焦点
