# ADR-0007：依赖版本相对设计文档的偏离

- 状态：已采纳
- 日期：2026-07-27

## 背景

技术选型文档写于草案期，点名 React 18。施工时（2026-07-27）这些库都已有更新的稳定版。

## 决策

用当前稳定版，并在这里记录偏离：

| 项目         | 设计文档 | 实际采用                  | 理由                                                                                  |
| ------------ | -------- | ------------------------- | ------------------------------------------------------------------------------------- |
| React        | 18       | **19.2**                  | 18 已不是主线；19 的并发特性对画布与流式输出有直接收益                                |
| TypeScript   | 未指定   | **5.9**（而非最新的 7.0） | TS 7 是原生编译器移植版，生态工具（vitest / oxlint / 类型定义）尚在跟进。基座阶段选稳 |
| Vite         | 未指定   | **6.4**                   | `packages/ui` 要与 Preview.js 插件内置版本对齐；统一到 6.x 避免两套                   |
| Zod          | 未指定   | **4.4**                   | `z.toJSONSchema()` 内置，省掉一层生成器依赖                                           |
| Rust edition | 未指定   | **2024**                  | 工具链是 1.97，edition 2024 已稳定                                                    |

## 复审时机

- TS 7 生态稳定后升级（关注 vitest / oxlint 的官方支持）
- Vite 8：等 Preview.js 插件跟进，或组件预览完全改用自建画廊后
